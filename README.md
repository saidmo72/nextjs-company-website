# Weser Bau & Objektservice | Real-World Company Website

A modern, responsive business website developed for **Weser Bau & Objektservice**, an established German company providing construction and property services.

This is a **real-world client project**, developed and deployed for an operating business with real customers.

The website helps the company present its services, showcase its projects, strengthen its online presence, and connect with potential customers.

## ✨ Website Features

### Responsive Design

A modern layout designed to work across different screen sizes, including desktop computers, tablets, and smartphones.

### German-Language Website

The website provides a German-language user interface for the company's customers.

### Homepage

A professional homepage introducing the company and presenting its main services.

### Services Page (Leistungen)

A dedicated page explaining the services offered by the business.

### Projects Page (Projekte)

A portfolio section displaying the company's work and completed projects.

### Contact Page (Kontakt)

A contact page with a form for customer inquiries.

The project includes a server-side API route for email handling using Resend. Email delivery requires valid production configuration.

### Legal Information (Impressum)

A dedicated page for the company's legal information.

## 💻 Run the Project Locally

To run this project on your local machine:

### 1. Clone the repository

```bash
git clone https://github.com/saidmo72/nextjs-company-website.git
```

### 2. Open the project folder

```bash
cd nextjs-company-website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the following address in your browser:

http://localhost:3000

**Note:** Email functionality requires additional environment configuration. API keys and other secrets are not included in this repository.
